## 拍的时候注意

1. **用浅色主题拍**，或者全部用深色 —— 别一半浅一半深，看着像两个软件。
2. **裁掉无关部分**。整屏 2560px 贴进去，读者要眯着眼找你说的那个按钮。
   只留"目标按钮 + 够认出它在哪的周边"。
3. **第 3 张要标注**（左侧星星 + 右下角状态栏两处圈红）。其余的如果目标明显可以不标。
   Mac 自带「预览」就能圈：工具 → 标注 → 形状。
4. **别放个人信息**：文件名、路径、邮箱、公司内部项目名该打码就打码。
   第 7、8 张尤其容易带出来。
5. **宽度控制在 1200px 左右**。GitHub 上超过这个宽度会被压缩得发虚。

## 两张你拍不了原样的

- **第 1 张**（VS Code 下载页）：你已经装过了，但下载页随时能打开，照常拍。
- **第 2 张**（搜扩展）：你那儿会显示「已安装 / 卸载」而不是「Install」。
  要么找台没装过的机器，要么先卸载再拍（不推荐），要么就这样——
  读者能看懂"在这里搜、点这个按钮"就够了。
